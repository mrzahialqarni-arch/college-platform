# المنصة الموحدة للكليات — نموذج تجريبي

نموذج تجريبي غير رسمي لأداة تجمع بيانات أنظمة الجامعة في مكان واحد، وتعرضها على ثلاثة مستويات:

- **لوحة الكلية:** مقارنة الأقسام، والطلبات المعلّقة لدى المجالس، والإنتاج العلمي، والشكاوى، وتنبيهات العمادة.
- **لوحة القسم:** توزيع العبء التدريسي، وجدول مجلس القسم، وشكاوى الطلاب، وأعضاء القسم وتنبيهاتهم.
- **صفحة العضو:** طلباته من كل الأنظمة في قائمة واحدة، وعبؤه ومستحقاته، وجاهزية ترقيته، وأبحاثه.

## طريقة الاستخدام

1. افتح الموقع. تظهر بيانات توضيحية لعرض طريقة العمل.
2. نزّل القالب الفارغ من زر «تنزيل القالب الفارغ» واملأه ببيانات مُصدَّرة من الأنظمة (التعليمات داخل القالب).
3. اضغط «افتح ملف Excel» واختر الملف المعبأ.

## الخصوصية

- يُقرأ ملف Excel **داخل متصفح المستخدم فقط**. لا يُرفع إلى أي خادم، ولا يُحفظ بعد إغلاق الصفحة.
- **لا تُرفع أي بيانات حقيقية إلى هذا المستودع.** ملف `.gitignore` يمنع رفع ملفات Excel وCSV، باستثناء القالب الفارغ.

## الملفات

| الملف | الوصف |
| --- | --- |
| `index.html` | الأداة كاملة في صفحة واحدة |
| `vendor/xlsx.full.min.js` | مكتبة SheetJS لقراءة ملفات Excel (رخصة Apache 2.0، انظر `vendor/XLSX-LICENSE`) |
| `template/platform-data-template.xlsx` | قالب البيانات الفارغ |

## النشر

الموقع منشور عبر GitHub Pages من الفرع الرئيسي. أي تعديل يُرفع إلى الفرع يظهر على الموقع خلال دقائق.

## حالة المشروع

نموذج للعرض والتجربة، وليس نظاماً رسمياً معتمداً من الجامعة. المرحلة التالية: ربط آلي بالأنظمة عبر صلاحيات قراءة، واستضافة داخل بيئة الجامعة، وتسجيل دخول موحد.
